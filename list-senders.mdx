Use it to find the `senderId` you need to send messages, and to check how many credits each Sender has left.

## Headers

<ParamField header="x-api-key" type="string" required>
  Your API key, for example `gliiv_xxxxxxxxxxxxxxxx`. Create one in **Settings → API Keys**.
</ParamField>

## Query parameters

<ParamField query="page" default="1" type="number">
  The page to return, starting at `1`.
</ParamField>

<ParamField query="limit" default="50" type="number">
  How many Senders to return per page.
</ParamField>

<ParamField query="sortBy" type="string">
  The field to sort by: `balance` or `createdAt`.
</ParamField>

<ParamField query="sortDirection" type="string">
  The sort order: `asc` (lowest or oldest first) or `desc` (highest or newest first).
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.gliiv.com/v1/api/senders?page=1&limit=50&sortBy=balance&sortDirection=desc" \
  -H "x-api-key: $GLIIV_API_KEY"
```

```javascript Node.js
const params = new URLSearchParams({
  page: "1",
  limit: "50",
  sortBy: "balance",
  sortDirection: "desc",
});

const response = await fetch(`https://api.gliiv.com/v1/api/senders?${params}`, {
  headers: { "x-api-key": process.env.GLIIV_API_KEY },
});

console.log(response.status, await response.json());
```

```python Python
import os
import requests

response = requests.get(
    "https://api.gliiv.com/v1/api/senders",
    headers={"x-api-key": os.environ["GLIIV_API_KEY"]},
    params={"page": 1, "limit": 50, "sortBy": "balance", "sortDirection": "desc"},
)

print(response.status_code, response.json())
```

## Response

<ResponseField name="senders" type="object[]">
  The Senders on this page.

  <Expandable title="Sender object">
    <ResponseField name="id" type="string">
      The Sender's unique ID. Use it as `senderId` when sending messages.
    </ResponseField>

    <ResponseField name="name" type="string">
      The name recipients see as the message source, for example `GLIIV`.
    </ResponseField>

    <ResponseField name="balance" type="number">
      The Sender's credit balance. One SMS to one recipient costs 1 credit.
    </ResponseField>

    <ResponseField name="user" type="object">
      The account that owns the Sender, shown as **Owner** in the dashboard.

      <Expandable title="properties">
        <ResponseField name="name" type="string">
          The owner's name.
        </ResponseField>

        <ResponseField name="id" type="string">
          The owner's unique ID.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="createdAt" type="string">
      When the Sender was created.
    </ResponseField>

    <ResponseField name="updatedAt" type="string">
      When the Sender was last changed, for example after a balance update.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="number">
  The total number of Senders on your account, across all pages.
</ResponseField>

## Dates and times

`createdAt` and `updatedAt` are in **UTC**, in ISO 8601 format with a `Z` at the end. The dashboard shows the same moments in Rwanda time (UTC+02:00), so `2026-11-09T08:15:00.000Z` appears there as **9 Nov 2026, 10:15**.

## Pagination

To get every Sender, keep requesting the next `page` until you've received `total` Senders. The number of pages is `total ÷ limit`, rounded up.

<Tip>
  Most accounts have only a few Senders, so the default `limit` of 50 usually returns all of them in one request.
</Tip>

## Errors

| Status | Meaning | What to do |
| :-- | :-- | :-- |
| `401` | The API key is missing, invalid, expired, rotated or deleted. | Check the `x-api-key` header and the key in **Settings → API Keys**. |
| `429` | You've sent more than 60 requests in a minute with this key. | Wait the number of seconds in the `Retry-After` header, then try again. |
| `500` | Something went wrong on Gliiv's side. | Wait a moment and try again. If it keeps happening, contact [hello@gliiv.com](mailto:hello@gliiv.com). |
