<Update label="November 2026" description="v1.1.0">
  ## New

  - **Linked accounts** – see your connected Google and GitHub accounts under Profile → Settings
  - **API key rotation** – rotate your API keys from the dashboard
  - **Reschedule campaigns** – change the date of a scheduled campaign
  - **Email preferences** – choose which emails you receive
  - **New email notifications** – welcome email, plus emails when a campaign is cancelled or an API key is created, rotated, revoked or deleted

  ## Improved

  - SMS segments are now counted accurately for messages with emojis and other special characters
  - Refreshed campaign update emails and notifications UI
  - If you use an authenticator app, it's now the first 2FA method
  - Stronger 2FA email safeguards and a smoother OTP input
  - Clearer error page when Google or GitHub sign-in fails
  - Accessibility improvements across buttons and actions

  ## Fixed

  - Logout glitch
  - Autofocus in sheets and dialogs
  - Failed campaigns now always include a failure code (`SYSTEM_ERROR` when no specific reason applies)
</Update>
