A campaign sends one message to a list of phone numbers from the dashboard. Send it **immediately**, and it enters the sending queue as soon as you submit. Or **schedule** it, and Gliiv prepares it and sends it at the time you choose.

To start, go to **Campaigns** and click **Create Campaign**.

## 1. Sender

Choose the **Sender** your message comes from. This is the name recipients see. Only Senders approved for your account appear in the dropdown, and the campaign's credits are taken from that Sender's balance.

<Tip>
  No Senders in the list? Senders are assigned by the Gliiv team for compliance. Request one at [hello@gliiv.com](mailto:hello@gliiv.com) or +250 788 450 080. It appears in your **Senders** tab once it's approved.
</Tip>

## 2. Message

Type your message in plain text, up to **800 characters**. Under the message box, a live counter shows how many characters you've used and how many SMS each recipient will cost.

```text Standard message
Hello! Our offices will be closed on Friday. We reopen on Monday at 8:00.
```

To give each person their own details, add placeholders: column names from your file between double curly braces.

```text Personalized message (file upload only)
Hello {{name}}, your balance is {{amount}} RWF.
```

<Tip>
  Placeholders only work when you upload a file. A placeholder must match a column header exactly, including capital letters, so `{{Name}}` won't match a column called `name`.
</Tip>

## 3. How credits are charged

**One SMS to one person costs 1 credit.** A long message is split into several SMS. The recipient still sees one message, but each part costs 1 credit.

**Total credits = recipients × credits per recipient**

How many SMS a message needs depends on its length and on the characters it contains:

<Tabs>
  <Tab title="Normal text">
    Messages that use only standard letters, numbers and common punctuation.

    | Message length | Credits per recipient |
    | :-- | :-- |
    | 1–160 characters | 1 |
    | 161–306 characters | 2 |
    | 307–459 characters | 3 |
    | 460–612 characters | 4 |
    | 613–765 characters | 5 |
    | 766–800 characters | 6 |
  </Tab>
  <Tab title="With special characters">
    Messages that contain at least one emoji or other special character.

    | Message length | Credits per recipient |
    | :-- | :-- |
    | 1–70 characters | 1 |
    | 71–134 characters | 2 |
    | 135–201 characters | 3 |
    | 202–268 characters | 4 |
    | 269–335 characters | 5 |

    A message with special characters can be up to **335 characters** long.
  </Tab>
</Tabs>

<Note>
  Why 153 and 67 instead of 160 and 70? When a message is split, each part carries a small hidden header that tells the phone how to join the parts back together. That header takes up space, so each part holds slightly fewer characters.
</Note>

**Why one character can change the cost.** SMS uses a standard alphabet called [GSM-7](https://en.wikipedia.org/wiki/GSM_03.38), which covers English letters, numbers and common punctuation. If your message contains even one character outside that alphabet, such as an emoji, a curly quote or certain accented letters, the **whole message** has to be sent in a larger format called Unicode. That format fits only 70 characters in one SMS instead of 160, so the same message can cost two or three times more.

These are the most common causes, and what to type instead:

| Instead of this | Type this |
| :-- | :-- |
| Curly quotes `“ ”` and `‘ ’` | Straight quotes `"` and `'` |
| Long dashes `–` and `—` | A hyphen `-` |
| Ellipsis `…` | Three dots `...` |
| Accented letters such as `á`, `ê`, `ô` | Plain letters `a`, `e`, `o` |
| Emoji such as 😊 🎉 | Remove them |

<Tip>
  Curly quotes and long dashes usually sneak in when you copy text from Word, Google Docs or a phone's notes app. Check the live counter after pasting. If it jumps from 160 to 70 characters per SMS, look for one of the characters above.
</Tip>

Some symbols are part of the GSM-7 alphabet but count as **2 characters** each: `^ { } \ [ ] ~ | €`

<Note>
  For personalized messages, the count is based on each person's final message, after their details are filled in. A long name or amount can add one extra SMS for that person, so the total cost can vary slightly from person to person.
</Note>

## 4. Recipients

Gliiv sends to **Rwandan numbers only**. You can write numbers as `+2507XXXXXXXX`, `2507XXXXXXXX`, `07XXXXXXXX` or `7XXXXXXXX`, and you can mix formats in the same list.

<Tabs>
  <Tab title="Manual input">
    - Type or paste **one number per line**.
    - Up to **1,000 characters** in total.
    - Placeholders aren't supported. Anything like `{{name}}` is sent exactly as typed.

    ```text Recipients
    07XXXXXXXX
    +2507XXXXXXXX
    7XXXXXXXX
    ```
  </Tab>
  <Tab title="File upload">
    - Upload a **CSV** or **Excel** file, up to **20 MB**.
    - The first column must be named `phone`, in lowercase.
    - Any other column can be used as a placeholder in your message.

    ```csv contacts.csv
    phone,name,amount
    07XXXXXXXX,Aline,5000
    +2507XXXXXXXX,Eric,12000
    ```
  </Tab>
</Tabs>

<Tip>
  Use manual input for a handful of numbers and file upload for anything larger, or whenever you want to personalize the message.
</Tip>

## 5. Scheduling

To send now, leave **Schedule Message?** off and click **Submit**. To send later, turn it on and pick a date and time:

- **Minimum lead time:** at least **3 hours** from now.
- **Time intervals:** times go in **5-minute** steps (14:00, 14:05, 14:10…).
- **Time zone:** all times are in **Rwanda time (CAT, UTC+02:00)**, the time shown in the dashboard header.

<Tip>
  To send sooner than 3 hours from now, send the campaign immediately instead.
</Tip>

## 6. Tracking and statuses

After you submit, follow your campaign's progress on the **Campaigns** page.

<Tabs>
  <Tab title="Campaign status">
    | Status | Meaning |
    | :-- | :-- |
    | `staged` | Checking recipients and counting SMS per message. |
    | `processed` | Each person's message is ready, with placeholders filled in. |
    | `scheduled` | Waiting for the date and time you picked. |
    | `dispatched` | Handed to the mobile networks for delivery. |
    | `completed` | Every message in the campaign has been handled. |
    | `cancelled` | Stopped before it was sent. |
    | `failed` | The campaign couldn't be sent. See **Campaign failures**. |
  </Tab>
  <Tab title="Campaign failures">
    | Code | Meaning |
    | :-- | :-- |
    | `BAD_FILE_DATA` | The file couldn't be read, or its first column isn't named `phone`. |
    | `LOW_BALANCE` | The Sender doesn't have enough credits (recipients × credits per recipient). |
    | `USER_CANCELLED` | Someone on your account cancelled the campaign. |
    | `USER_BANNED` | Your account is suspended. Contact the Gliiv team. |
    | `SYSTEM_ERROR` | An internal error interrupted the campaign. Try again. |
  </Tab>
  <Tab title="Message failures">
    A campaign can complete while a few individual messages fail. Each failed message shows one of these codes:

    | Code | Meaning |
    | :-- | :-- |
    | `INVALID_NUMBER` | Not a valid Rwandan mobile number. |
    | `EMPTY_CONTENT` | The message had no text to send. |
    | `LOW_BALANCE` | The Sender ran out of credits before this message was sent. |
    | `USER_CANCELLED` | The campaign was cancelled before this message was sent. |
    | `USER_BANNED` | Your account is suspended. |
    | `SYSTEM_ERROR` | An internal error stopped this message. |
  </Tab>
</Tabs>
