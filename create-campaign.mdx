The campaign creation process allows for both immediate dispatch and precise future planning. Once submitted, the Gliiv engine handles all background processing and carrier routing.

## 1. Sender Selection

Select an identity from the **Sender** dropdown. This list contains the Senders that have been authorized for your account.

## 2. Message Composition

The **Message** field is where you define your SMS content.

<Tip>
  Below are examples of how you might format your message based on your chosen input method:

  <CodeGroup>

  ```text Standard (Plain Text)
  Hello! Our annual clearance sale starts tomorrow at 8:00 AM. 
  Visit our store for up to 50% off on all items.
  ```

  ```text Personalized (File Upload Only)
  Dear {{name}}, your balance for account {{account_no}} is {{balance}} RWF. 
  Please settle by {{due_date}} to avoid service interruption.
  ```

  </CodeGroup>
</Tip>

### How credits are charged

Each SMS costs **1 credit per recipient**. Short messages fit in one SMS. Longer messages are split into several SMS behind the scenes, but your contact still receives them as **one message**.

Under the **Message** box you'll see a live counter, for example `103 characters · 1 SMS`. That number is what each recipient will cost.

<Tabs>
  <Tab title="Normal text">
    Letters, numbers and common punctuation.

    | Message length | Credits per recipient |
    | :-- | :-- |
    | 1 – 160 characters | 1 |
    | 161 – 306 characters | 2 |
    | 307 – 459 characters | 3 |
    | 460 – 612 characters | 4 |
    | 613 – 765 characters | 5 |
    | 766 – 800 characters | 6 |
  </Tab>
  <Tab title="With special characters">
    Applies if your message contains even **one** special character (see below).

    | Message length | Credits per recipient |
    | :-- | :-- |
    | 1 – 70 characters | 1 |
    | 71 – 134 characters | 2 |
    | 135 – 201 characters | 3 |
    | 202 – 268 characters | 4 |
    | 269 – 335 characters | 5 |
  </Tab>
</Tabs>

<Note>
  Why isn't it 320 for 2 SMS? When a message is split, each part keeps a few characters to join the parts back together on the phone, so each part holds 153 characters (or 67 with special characters).
</Note>

### Special characters

Some characters make each SMS hold **70 characters instead of 160**. This happens because SMS has its own standard alphabet (called GSM-7); any character outside it switches the whole message to a larger format (called Unicode). So the same message can cost more than double. When this happens, the form shows a warning under the **Message** box listing the characters.

The most common ones come from copying text out of Word, Google Docs or WhatsApp:

| Instead of this | Type this |
| :-- | :-- |
| Curly quotes `’ ‘ “ ”` | Straight quotes `' "` |
| Long dashes `– —` | A normal hyphen `-` |
| The ellipsis `…` | Three dots `...` |
| Accented letters such as `á í ó ú ê ç` | The plain letter `a i o u e c` |
| Emoji 😀 | Remove them |

<Tip>
  To avoid surprises, type your message directly in the box, or paste it into a plain-text editor first, then check the counter before you submit.
</Tip>

A few normal symbols are allowed but **count as 2 characters**: `^ { } \ [ ] ~ | €`. That includes the braces in placeholders, so `{{name}}` counts as 12 characters before it's filled in.

<Note>
  For personalized messages, the count is based on each contact's message **after** the placeholders are filled in. A long name or amount can push one contact's message into an extra SMS.
</Note>

The maximum length for a single message is **800 characters**.

## 3. Recipient Input Method

Choose the method that best fits your workflow. Both methods support high-volume distribution.

<Tabs>
  <Tab title="Manual Input">
    ### Direct Entry

    Paste or type numbers directly into the text area for immediate processing.

    - **Formatting:** Enter phone numbers one per line.
    - **Input Limit:** This field supports a maximum of **1,000 characters** of raw number data.
    - **Note:** Personalization placeholders are **not supported** in Manual Input; they will be sent as plain text.
  </Tab>
  <Tab title="File Upload">
    ### Spreadsheet Processing

    Upload a CSV or Excel file (maximum **20MB**) for large-scale outreach and personalization.

    - **Primary Column:** The first column must be named `phone` (case-sensitive).
    - **Placeholder Mapping:** Use `{{brackets}}` that match your column headers (e.g., `{{name}}`).
    - **Validation:** Headers are case-sensitive. `{{Amount}}` will not work if your column is named `amount`.
    - **Number Formatting:** Supported formats: `+250...`, `250...`, `07...`, or `7...`.
  </Tab>
</Tabs>

## 4. Scheduling

The **Schedule Message?** toggle allows you to set a future dispatch time.

- **Lead Time:** Scheduled campaigns must be set at least **3 hours** in advance to allow for system staging.
- **Intervals:** The time selector uses **5-minute intervals** for synchronization.

## 5. Tracking & Statuses

Monitor your campaign's lifecycle in the **Campaigns** tab.

### Lifecycle Status

| Status | Description |
| :-- | :-- |
| <span style={{color: '#3182CE'}}>**STAGED**</span> | The system is validating recipients and counting how many SMS each message needs. |
| <span style={{color: '#805AD5'}}>**PROCESSED**</span> | Messages are generated and mapped to placeholders. |
| <span style={{color: '#38A169'}}>**DISPATCHED**</span> | The campaign has been handed over to carriers for delivery. |
| <span style={{color: '#DD6B20'}}>**SCHEDULED**</span> | The campaign is queued for its designated future time. |
| <span style={{color: '#718096'}}>**CANCELLED**</span> | The campaign was manually stopped before it reached the dispatch phase. |
| <span style={{color: '#E53E3E'}}>**FAILED**</span> | An error occurred during processing or dispatch. |

### Failure Diagnostics

If a campaign shows a **FAILED** status, check the detail view for these specific system codes:

| Error Code | Meaning |
| :-- | :-- |
| `USER_CANCELLED` | The campaign was manually stopped by a user. |
| `BAD_FILE_DATA` | Structural issues, incorrect encoding, or missing `phone` header in the upload. |
| `LOW_BALANCE` | Insufficient account credits to cover the campaign (recipients × SMS per message). |
| `SYSTEM_ERROR` | An internal system interruption occurred during processing. |
