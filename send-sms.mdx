Sends one message to one or more phone numbers, right away. Use it for one-time passwords, alerts, order updates and other messages your system sends automatically.

The API sends immediately and doesn't support scheduling. To schedule messages, create a campaign in the dashboard.

## Headers

<ParamField header="x-api-key" type="string" required>
  Your API key, for example `gliiv_xxxxxxxxxxxxxxxx`. Create one in **Settings → API Keys**.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  Must be `application/json`.
</ParamField>

## Body

<ParamField body="phoneNumbers" type="string[]" required>
  The recipients' phone numbers, **1 to 20** per request. Rwandan numbers only, in any of these formats: `+2507XXXXXXXX`, `2507XXXXXXXX`, `07XXXXXXXX` or `7XXXXXXXX`. You can mix formats in the same request.
</ParamField>

<ParamField body="message" type="string" required>
  The text to send. Up to **800 characters** of standard text, or up to **335 characters** if it contains emoji or other special characters.
</ParamField>

<ParamField body="senderId" type="string" required>
  The **ID** of the Sender to send from, not its display name. In the dashboard, open **Senders**, click **⋯** in the Actions column, and choose **View details**. You can also get it from the List senders endpoint.
</ParamField>

```bash cURL
  -H "x-api-key: $GLIIV_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "phoneNumbers": ["+2507XXXXXXXX", "07XXXXXXXX"],
    "message": "Your Gliiv verification code is 482913. It expires in 10 minutes.",
    "senderId": "6650f1c2a9e4b7d3c1a2b3c4"
  }'
```

```python Python
import os
import requests

response = requests.post(
    "https://api.gliiv.com/v1/api/messages/send",
    headers={"x-api-key": os.environ["GLIIV_API_KEY"]},
    json={
        "phoneNumbers": ["+2507XXXXXXXX", "07XXXXXXXX"],
        "message": "Your Gliiv verification code is 482913. It expires in 10 minutes.",
        "senderId": "6650f1c2a9e4b7d3c1a2b3c4",
    },
)

print(response.status_code, response.json())
```

## Response

<ResponseField name="message" type="string">
  A short description of the result.
</ResponseField>

<ResponseField name="status" type="number">
  The HTTP status code, repeated in the body.
</ResponseField>

<ResponseField name="validationErrors" type="object">
  Only on `400` responses. Each key is a field that failed (`phoneNumbers`, `message` or `senderId`), and its value explains why.
</ResponseField>

## What a 200 response means

A `200` means Gliiv has **accepted** your request and queued the messages for sending. It doesn't mean the messages have reached the phones yet. Delivery normally follows within seconds.

## Credits

Credits are taken from the balance of the Sender you send from:

**Credits used = number of phone numbers × SMS per message**

A message of up to 160 standard characters is 1 SMS. Longer messages are split into parts of 153 characters, and each part costs 1 credit. If the message contains an emoji or another special character, the limits drop to 70 characters for one SMS and 67 per part. The Create a campaign page explains the full rules.

## Errors

| Status | Meaning | What to do |
| :-- | :-- | :-- |
| `400` | A field is missing or invalid. | Read `validationErrors` to see which field failed, fix it, and send again. |
| `401` | The API key is missing, invalid, expired, rotated or deleted. | Check the `x-api-key` header and the key in **Settings → API Keys**. |
| `404` | No Sender matches `senderId` on your account. | Copy the Sender ID again from **⋯ → View details**. |
| `429` | You've sent more than 60 requests in a minute with this key. | Wait the number of seconds in the `Retry-After` header, then try again. |
| `500` | Something went wrong on Gliiv's side. | Wait a moment and try again. If it keeps happening, contact [hello@gliiv.com](mailto:hello@gliiv.com). |

<Tip>
  To message more than 20 people, split the numbers into groups of 20 and send one request per group, staying within 60 requests per minute. For lists of thousands, a dashboard campaign with a file upload is easier.
</Tip>
